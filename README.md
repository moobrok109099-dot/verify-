# verify-
🌸 سياسة الخصوصية وشروط الخدمة - Girl Verification Bot

1- جمع البيانات:
يقوم البوت بجمع وتخزين معرفات المستخدمين (User IDs) ومعلومات السيرفر الضرورية فقط لأداء وظيفة التوثيق وحمايته.

2- أمان المعلومات:
نحن نضمن حماية جميع البيانات المخزنة وعدم مشاركتها أو بيعها لأي أطراف خارجية أو استخدامها في غير الغرض المخصص لها.

3- الاستخدام:
يقتصر استخدام هذه البيانات على تسجيل وتتبع حالات التوثيق داخل السيرفرات الرسمية للبوت فقط.
